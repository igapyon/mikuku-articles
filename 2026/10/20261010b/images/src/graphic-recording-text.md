# GPT-5.6 Lunaも衝撃価格だったのに、GPT-6ではSolもLunaもさらに安い

## 主題

- GPT-5.6で値下がりしたSol・Terra・Lunaに対し、GPT-6ではSolとLunaの標準単価がさらに下がった。
- 選ぶ基準はトークン単価だけではなく、必要な品質で仕事を完了するまでの費用。
- 現在の仮説は、計画・難しい作業にGPT-6.1 Sol `xhigh`、普段の実行にGPT-6 Luna `xhigh`。自分の作業で確かめる。
- GPT-6系列にTerraの後継は掲載されていないが、GPT-5.6 Terra自体はAPIに掲載中。

## 関係・流れ・対比

### 標準単価の推移

100万トークンあたり、Standard・短いコンテキストの通常入力／出力（米ドル）。

| モデル | GPT-5.6初期 | GPT-5.6・2026-10-10 | GPT-6系列・2026-10-10 |
| --- | ---: | ---: | ---: |
| Astra | — | — | $10 / $50 |
| Sol | $5 / $30 | $4 / $20* | $2 / $10 |
| Terra | $2.50 / $15 | $2 / $12 | —（後継の掲載なし） |
| Luna | $1 / $6 | $0.20 / $1.20 | $0.10 / $0.50 |

`* GPT-5.6 Solの$4 / $20は期間限定価格。Terraの後継が見当たらないことは、Terraの提供終了を意味しない。`

### 同じトークン量でのLuna料金例

`入力10万 + 出力10万（キャッシュなし）`

`GPT-5.6 Luna 約$0.14 → GPT-6 Luna 約$0.06（合計で約57%減）`

これはAPI単価だけの計算例。実際の一つの依頼が必ず同じトークン量になるわけではない。

### 単価と、仕事を終えるまでの費用

`入力 + 出力（推論トークンを含む） + キャッシュ + やり直し + ツール料金 + 時間`

単価が下がっても、入力文脈・回答量・キャッシュ・やり直し・必要品質によって、タスク全体の費用は変わる。

### GPT-6.1 Solの処理区分

短いコンテキストの通常入力単価をStandard比で表示。

| 処理区分 | 通常入力の倍率 | 入力 / キャッシュ入力 / キャッシュ書き込み / 出力 |
| --- | ---: | ---: |
| Standard | 1x | $2 / $0.10 / $2.50 / $10 |
| Batch / Flex | 0.5x | $1 / $0.05 / $1.25 / $5 |
| Fast | 2x | $4 / $0.20 / $5 / $20 |
| Ultrafast | 6x | $12 / $0.60 / $15 / $60 |

`UltrafastはStandardの6倍。入力が272Kトークンを超える場合、超過分だけでなくリクエスト全体に長いコンテキスト料金が適用。GPT-6.1 Solは入力・キャッシュ関連2倍、出力1.5倍。`

### 公表ベンチマーク

- AutomationBenchのGPT-6 Luna `high`: 前モデルよりスコア +5.4ポイント、タスクあたり費用 −58%というOpenAI発表。
- 特定ベンチマークの結果であり、すべての普段の作業に同じ差が出るとは限らない。

## 正確性メモ

- 記事本文に記載された価格・倍率・日付・ベンチマーク値だけを使う。
- 通常入力／出力と、GPT-6.1 Solの処理区分別価格を混同しない。
- GPT-5.6 Solの$4 / $20は期間限定。API標準価格と混同しない。
- Terraの後継が主力モデル一覧に見当たらないことを、Terra自体の提供終了と表現しない。
- AutomationBenchの数値は特定ベンチマークでの公表値として扱う。
- `GPT-5.6 Luna`の入力10万＋出力10万は約$0.14、`GPT-6 Luna`は約$0.06。合計差は約57%。
- GPT-6.1 Solの長文脈料金は、入力272Kトークン超でリクエスト全体へ適用される。
- 価格はAPI利用料金。CodexやChatGPTの定額プラン利用枠とは別。
