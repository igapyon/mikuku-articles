# 四つの出力先を、ひとつのSkillから選ぶ

## 主題

- 図内題名: 欲しい形式を、ひとつ選ぶ
- 入力Markdownだけでは出力形式が決まらない。変換先を明示してもらい、Skillが同梱CLIへ案内する。今回はPDFや画像出力を含めない。

## 図解キーワード

- igapyon-miku-md2formats
- HTML
- DOCX
- XLSX
- PPTX
- 変換先を明示
- ローカルCLI

## 関係・流れ・対比

- 変換先を明示した依頼 → SkillがローカルCLIへ案内 → 選んだ出力形式

## 図解構造

- layout-family: decision
- primary-relation: 変換先を明示した依頼 → SkillがローカルCLIへ案内 → 選んだ出力形式

## グラレコ構図案

- 左: 依頼の吹き出し型パネル「このMarkdownをHTMLにして」。
- 中央: 主図はSkill「igapyon-miku-md2formats」と、その下の選択パネルにHTML / DOCX / XLSX / PPTXの四カード。HTMLだけ選択チェックを付ける。
- 右: 「ローカルCLI」から「HTML」の選択された出力例。下に小さな注意「PDF・画像への変換は今回は対象外」。
- 最も大きく見せる主図: 上記のprimary-relation。左右と中央の関係を明確にする。
- みくくの表情・視線: 画面の右下、または指定がある場合は中央下。画面の20%程度の大きさで1人。やわらかな少し照れた説明表情で主図を見る。キャラの外観は正本を維持。何も持たない。自然な空の手。
- 吹き出し: どの形式にしましょうか。

## 正確性メモ

- 対象セクションの本文だけに基づく。四形式を一度に全部生成する図ではなく、明示された形式を選ぶ図。出力形式同士の変換矢印は禁止。
- 設計文は印刷せず、題名・短いラベル・吹き出しだけを画像内に描く。出力形式カード同士を連続変換する矢印を描かない。足りない情報を別セクションから補わない。

## 共通スタイル契約

- style-profile: mikuku-graphic-recording-v1
- 横長3:2、左・中央・右の3領域、主図を最大化
- 均一に明るい白〜薄いアイボリー。濃色の読みやすい文字。淡い暖色、ティールの囲み、手描き線と矢印。暗い陰影やビネットなし。
- fully opaque background; no transparent or semi-transparent pixels
- みくくは説明役として読める大きさで1人、短い吹き出しを1つ、物を持たない
