# 週次報告の元ネタにも使える

## 主題

- 日々の活動記録を、週次報告を書くための材料として振り返れる。
- AIエージェントに対象期間の活動記録を読んでもらい、報告の元ネタを箇条書きに整理できる。
- 人が元記録と見比べて内容を選び、自分の言葉で報告を仕上げる。

## 図解キーワード

- 日々の活動記録
- 10月5日から9日
- 週次報告の元ネタ
- 箇条書き
- 元の記録と見比べる
- 内容を選ぶ
- 自分の言葉で仕上げる

## 関係・流れ・対比

| 段階 | 内容 |
| --- | --- |
| 日々 | 短い「やったこと」を活動記録に残す |
| 振り返り | 10月5日から9日の活動記録を読み、週次報告の元ネタを箇条書きに整理する |
| 人の仕上げ | 元記録と照合して報告する内容を選び、自分の言葉でまとめる |

## 役割分担・判断軸

- AIエージェントは活動記録を整理して、箇条書きの材料を用意する。
- 人は元の記録と見比べ、報告に使う内容を選ぶ。
- 週次報告は人が自分の言葉で仕上げる。

## 図解構造

- layout-family: process
- primary-relation: 毎日の小さな活動記録を、AIの整理と人の確認を通して週次報告の材料にする

## グラレコ構図案

- 左: 月曜から金曜（10月5日〜9日）の小さな活動メモが並ぶ。
- 中央: AIエージェントが対象期間の記録を箇条書きの報告材料に整理する。
- 右: 人が元記録と照合して項目を選び、自分の言葉で週次報告に仕上げる。
- 最も大きく見せる主図: 「日々の記録 → 箇条書きの材料 → 人が仕上げる」の流れ。
- みくくの表情・視線: 記録を整理し、最後に人へバトンを渡す穏やかな表情。
- 吹き出し: 「毎日のメモが、報告の助けになります…」

## 正確性メモ

- 例示されている対象期間は10月5日から9日。
- AIが作るのは週次報告の元ネタとなる箇条書き。
- 人が元記録と見比べ、内容を選び、自分の言葉で報告を仕上げる。
- 架空の活動内容や成果、実在の曜日・年を付け足さない。

- みくくは説明役として読める大きさで1人、短い吹き出しを1つ、物を持たない
