# おわりに

## 主題

- 図内題名: 作ってきた道具を、次の「欲しい」へ
- MarkdownをHTMLで確認したいという出発点から、既存のMarkdown→Office側の半分を再利用して四形式をまとめた。小さく使える感覚を大切にする。

## 図解キーワード

- ちょっと使える道具
- HTML
- Word
- Excel
- PowerPoint
- 再利用
- 次の「欲しい」

## 関係・流れ・対比

- HTMLで確認したい → HTML変換と既存Officeツールの再利用 → 四つの出力先

## 図解構造

- layout-family: flow
- primary-relation: HTMLで確認したい → HTML変換と既存Officeツールの再利用 → 四つの出力先

## グラレコ構図案

- 左: 小さな要望「ちょっとHTMLで確認したい」とMarkdown書類。
- 中央: 主図は「HTML変換」＋「以前作ったMarkdown→Officeの道具を再利用」がつながる流れ。
- 右: 「HTML / Word / Excel / PowerPoint」の四カードを一つの出力先グループにまとめる。「次の『欲しい』を助ける」「ちょっと使える道具」を短い補足ラベルに。
- 最も大きく見せる主図: 上記のprimary-relation。左右と中央の関係を明確にする。
- みくくの表情・視線: 画面の右下、または指定がある場合は中央下。画面の20%程度の大きさで1人。やわらかな少し照れた説明表情で主図を見る。キャラの外観は正本を維持。何も持たない。自然な空の手。
- 吹き出し: 必要なときに、そっと使ってもらえたら。

## 正確性メモ

- 対象セクションの本文だけに基づく。Node.js/Javaやトークンの詳細はこの節の主題に入れない。新機能の予告を加えない。
- 設計文は印刷せず、題名・短いラベル・吹き出しだけを画像内に描く。出力形式カード同士を連続変換する矢印を描かない。足りない情報を別セクションから補わない。

## 共通スタイル契約

- style-profile: mikuku-graphic-recording-v1
- 横長3:2、左・中央・右の3領域、主図を最大化
- 均一に明るい白〜薄いアイボリー。濃色の読みやすい文字。淡い暖色、ティールの囲み、手描き線と矢印。暗い陰影やビネットなし。
- fully opaque background; no transparent or semi-transparent pixels
- みくくは説明役として読める大きさで1人、短い吹き出しを1つ、物を持たない
