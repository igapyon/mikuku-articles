# その支度も、生成AIに作ってもらう

## 主題

- 生成AIが読んで使う支度を、生成AIに書いてもらう。
- 目的や前提を渡し、作成・利用・改善をつなげる。

## 図解キーワード

- 目的・前提
- AIが支度を作る
- 使う
- 直す
- Agent Skills
- スクリプト
- 作業再開情報

## 関係・流れ・対比

```text
目的・前提を伝える → AIが支度を作る → 使う → 直す ↺
支度の例：Agent Skills ／ スクリプト ／ 作業再開情報
生成AIが使う道具を、生成AIが作る
```

## グラレコ構図案

- 画像内題名: その支度も、生成AIに作ってもらう
- 左: 「目的・前提」を渡す入り口と、支度の3例 Agent Skills・スクリプト・作業再開情報。
- 中央: 主図は大きな循環矢印。「AIが支度を作る」→「使う」→「直す」→作るへ戻る。下に「生成AIが使う道具を、生成AIが作る」の短い説明。

- みくくの表情・視線: 少し照れたやさしい困り顔。右側から左上の主図を見つめる。顔と胸元を自然に描き、手のジェスチャーや持ち物は加えない。
- 吹き出し: 支度づくりも、生成AIに担ってもらうのですね。

## 正確性メモ

- AIが書けば必ず読みやすくなるという保証を描かない。実際に使って改善する実践として表す。別節の MCP、人格、ユーモアは追加しない。
- セクション本文だけを使い、モデル名、数値、日付、価格、評価を新しく補わない。制作上の見出しやファイル名は画像内に描かない。
- 画像内題名と図解ラベルだけを描く。日本語は明瞭な濃色で、Agent Skills・MCP・GitHub と日本語の間には空白を入れる。
