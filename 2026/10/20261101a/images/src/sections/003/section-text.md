# 主格についての意識が、言葉を通じて、やり方につながる

## 主題

- 再開する相手を基準に、記述内容・粒度、置き場所、更新時期を整える。
- 主格の意識が言葉となり、仕事のやり方を導く。

## 図解キーワード

- 自分向けのメモ
- 生成AI向けの記録
- 記述内容・粒度
- 置き場所
- 更新時期
- 主格の意識
- 言葉
- やり方

## 関係・流れ・対比

```text
自分向けのメモ → 自分が思い出せる
生成AI向けの記録 → 現在地を把握 → 判断・実行できる
記録する内容：目的 ／ 決まったこと ／ 残っていること ／ 次にすること
主格の意識 → 言葉 → やり方
```

## 図解構造

- layout-family: comparison
- primary-relation: 自分向けのメモと、生成AIが判断して動くための記録の対比

## グラレコ構図案

- 画像内題名: 主格の意識 → 言葉 → やり方
- 左: 「自分向けのメモ」パネルに「思い出せる」。対比先へ矢印。
- 中央: 大きな「生成AI向けの記録」パネルに「現在地を把握」「判断・実行できる」。下に4つの小ラベル「目的」「決まったこと」「残っていること」「次にすること」。注記「記述内容・粒度」「置き場所」「更新時期」。下段に主格の意識→言葉→やり方のつながった矢印。Agent Skills や MCP の文字は補助的に扱い、主図を埋めない。
- 右: 説明役のみくく1人の大きな肩から上の肖像。画面の約20%を占め、クリーム色の襟付きブラウス、手指は完全に画面外。主図や文字を髪で隠さない。
- みくくの表情・視線: 少し照れたやさしい困り顔。右側から左上の主図を見つめる。顔と胸元を自然に描き、手のジェスチャーや持ち物は加えない。
- 吹き出し: 次の生成AIが動ける粒度で、残すのですね。

## 正確性メモ

- 情報を置くだけで自動的に読まれるとは描かない。「再開時に読む」という小ラベルを添える。人間全般が粗い記録でよいという主張にしない。
- セクション本文だけを使い、モデル名、数値、日付、価格、評価を新しく補わない。制作上の見出しやファイル名は画像内に描かない。
- 画像内題名と図解ラベルだけを描く。日本語は明瞭な濃色で、Agent Skills・MCP・GitHub と日本語の間には空白を入れる。

## 共通スタイル契約

- style-profile: mikuku-graphic-recording-v1
- 横長3:2、左・中央・右の3領域。主図を最大化し、適度な情報量を保つ。
- 均一に明るい白〜ごく薄いアイボリー。全面不透明、濃い茶や黒の読みやすい文字、やわらかな手描き線。淡い桃色と青緑の囲み。暗い周辺減光や汚れなし。
- みくくは説明役として読める大きさで1人、短い吹き出し1つ。手指は原則描写対象外として画面外に置き、不要な物を持たない。
- キャラクターの顔、目、茶色の長いツインテール、黒と深紅のリボンを保つ。
