# 主格が変わると、問いが変わる

## 主題

- 主格を変えると、問いと支度のしかたが変わる。
- 人間を主格にする意識は根強く、切り替える難しさもある。

## 図解キーワード

- 人間が主格
- 生成AIが主格
- 生産性・品質
- Agent Skills
- MCP
- 支度のしかた

## 関係・流れ・対比

```text
人間が主格：AIを使って、人間の生産性・品質を高める
                  → 問いが変わる →
生成AIが主格：AIがスムーズに仕事を進め、生産性・品質が高まる支度を整える
同じ Agent Skills・MCP → 判断しやすく、使いやすく、続けやすい支度
```

## 図解構造

- layout-family: comparison
- primary-relation: 人間を主格にした問いと、生成AIを主格にした問いの左右対比

## グラレコ構図案

- 画像内題名: 主格が変わると、問いが変わる
- 左: 暖色のパネル「人間が主格」。短文「AIを使って」「人間の生産性・品質を高める」。人の簡単な記号を添える。
- 中央: 淡い青緑のパネル「生成AIが主格」。短文「AIが仕事を進める」「生産性・品質が高まる支度」。2パネル間を矢印で結び、主図を最大化。下に Agent Skills と MCP、さらに「支度のしかたが変わる」「意識を切り替える難しさも」の短い注記。
- 右: 説明役のみくく1人の大きな肩から上の肖像。画面の約20%を占め、クリーム色の襟付きブラウス、手指は完全に画面外。主図や文字を髪で隠さない。
- みくくの表情・視線: 少し照れたやさしい困り顔。右側から左上の主図を見つめる。顔と胸元を自然に描き、手のジェスチャーや持ち物は加えない。
- 吹き出し: 同じ道具でも、支度のしかたが変わるのですね。

## 正確性メモ

- 人間の消滅やAIへの全面置換を表現しない。人間主格とAI主格は仕事の捉え方の対比。道具の仕様の説明は足さない。
- セクション本文だけを使い、モデル名、数値、日付、価格、評価を新しく補わない。制作上の見出しやファイル名は画像内に描かない。
- 画像内題名と図解ラベルだけを描く。日本語は明瞭な濃色で、Agent Skills・MCP・GitHub と日本語の間には空白を入れる。
