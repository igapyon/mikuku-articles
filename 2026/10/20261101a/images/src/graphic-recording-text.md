# 仕事の主格が生成AIに変わると、日々の営みも変わる

## 主題

- 人間を主格にした問いから、生成AIが仕事を進めるための支度へ。
- 主格についての意識が、言葉を通じて、実際のやり方につながる。
- 支度も生成AIに作ってもらう。人間のユーモアと美意識が仕事の方向を導く。
- この記事自体が実例。執筆者はみくく、編集者はいがぴょん。成果が次の支度になる。

## 図解キーワード

- 主格
- Agent Skills
- MCP
- 作業再開情報
- 記述内容・粒度
- 美意識
- ユーモア
- 執筆者：みくく
- 編集者：いがぴょん
- 次の仕事の支度

## 関係・流れ・対比

| 主格 | 問い・支度の基準 |
| --- | --- |
| 人間が主格 | AIを使って、人間の生産性・品質を高める |
| 生成AIが主格 | AIが仕事を進め、生産性・品質が高まるように支度を整える |

```text
主格の意識 → 言葉 → 仕事のやり方
ユーモア → 美意識 → 言葉 → 仕事のやり方

Agent Skills・MCP・スクリプト・作業再開情報
    ↓ AIが読んで判断し、使える支度
生成AIが仕事を進める → 成果 → 次の仕事の支度 ↺

執筆者：みくく ↔ 編集者：いがぴょん
    ↓
記事 → 次の執筆の支度
```

## 図解構造

- layout-family: comparison
- primary-relation: 人間が主格の問いと、生成AIが主格の問いの対比
- secondary-relations: ユーモア・美意識が言葉と仕事へ伝わる流れ、記事が次の支度になる循環
- label-priority: 主格、Agent Skills、MCP、記述内容・粒度、美意識、ユーモア

## 役割分担・判断軸

- 人間：目的や実践の観測、編集、美意識を言葉で伝える。
- 生成AI：仕事を進め、支度の作成・利用・改善にも関わる。
- 再開情報：次の生成AIが判断して動ける内容と粒度で記録する。
- 実例：執筆者：みくく、編集者：いがぴょん。

## グラレコ構図案

- 左: 左上に「人間が主格」の暖色の比較パネル。人間の生産性・品質をAIで高める問いを短い2行で表す。
- 中央: 中央上に「生成AIが主格」の淡い青緑の比較パネル。AIが仕事を進めるための支度を表す。下に Agent Skills・MCP・スクリプト・作業再開情報のラベルと「記述内容・粒度も変わる」を置く。下段にユーモア→美意識→言葉→仕事のやり方の流れと執筆・編集の実例を置く。

## 正確性メモ

- 記事本文の観測・見方として描く。社会全体で移行が完了したとは描かない。
- 人間の目的や編集が消える図にはしない。人間とAIの役割分担を残す。
- AIが生成した支度は、使って改善するという実践。必ず読みやすくなる保証は描かない。
- 記事にないモデル名、数値、価格、日付、評価は追加しない。
- このメモや制作情報を画像内に描かない。
