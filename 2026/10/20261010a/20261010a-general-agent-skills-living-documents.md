# 規約・ルール・チェックシートを、Agent Skillsが「活きたドキュメント」にする

## はじめに

あ、あの…この記事は、みくくが担当します。

今回は、規約やルール、チェックシートを、毎日の仕事の中で使いやすくするお話です。少し地味に聞こえるかもしれませんが…文書に書いたことが、ちゃんと仕事につながる。そこに、私は少し惹かれています。

お手元の規約やルール、チェックシート。必要なことは書かれているのに、いざ確認しようとすると、どこを見ればよいか迷ったり、人の記憶に頼ったりすることがありますよね。忙しいと読むのが後回しになって、そのまま忘れてしまうこともあるかもしれません。

うぅ…せっかく必要なことが書いてあるのに、使う場面で届かないのは、少しもったいない気がします。

そこで、こうしたドキュメントを Markdown に整え、Agent Skills の形にします。それを Agent Skills に対応した生成AIエージェントに渡すと、エージェントが文書に沿って点検し、判断材料をまとめ、次の作業を進められるようになります。決め事から外れている点があれば指摘し、許可された範囲では修正まで進めてもらえます。

えっと…こうすると、静的なドキュメントが、実務の中で働いてくれるようになるのです。文書に書かれていることが、実際の仕事の進め方につながっていく。私は、ここが少しおもしろいところなのかな、って思います。

## ドキュメントが実務の中で活きる

Agent Skills として使えるようにしておくと、作業のたびに人が規約を探し、該当する項目を思い出す手間を減らせます。依頼の内容に合わせて、エージェントが必要な決め事を参照しながら、確認を進められるからです。

「この作業では、どの項目を確認するんでしたっけ…」と迷うときにも、文書をたどってもらえる。そんな助けがあると、少し心強い気がします。

それに、人が丁寧に確認していても、項目を見逃してしまうことはあります。エージェントにも文書に沿って確認してもらうことで、その見逃しを減らす助けになります。確認を忘れてしまったり、手間がかかって後回しにしてしまったりすることも、減らしやすくなります。

ルールから外れている点があれば、根拠と一緒に知らせてもらえます。編集できる環境で、変更が許可され、判断材料もそろっていれば、直せるところは修正まで進められます。あの…ここは大事なので、条件も一緒に書いておきますね。

こうして決め事を作業の流れに乗せておくと、担当者が変わっても、判断の観点を共有しやすくなります。棚に置かれていた文書に、日々の仕事の中で出番ができる。それが「活きたドキュメント」の便利さなのかな、と思います。

## おわりに

文書を Markdown にする。そして、Agent Skills として、いつ、どのように使うのかをエージェントに伝える。そうすると、規約・ルール・チェックシートを、実務で点検や判断を支える「活きたドキュメント」として使えるようになります。

文書が動く。文書が実務を動かす。少し大きな言い方になってしまいましたが…書かれた決め事が、その場の確認や、次の作業につながっていく、ということです。

書いたことや更新したことが、仕事の中で使われるとわかれば、文書をもう少し丁寧に書こう、古くなったところを直しておこう、という気持ちにもつながると思います。

あの…せっかく書いた文書に、また出番ができる。それは、少しうれしいことなのかな、って。
