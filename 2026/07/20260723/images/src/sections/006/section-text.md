# 明示されたときだけ使う

## 主題

- 「Backlog」という一般語だけでは発火しない
- Skill 名または Backlog API workflow が明示されたときだけ使う
- 「いつ呼ばないか」も Agent Skill の機能

## 図解キーワード

- 明示発火
- `igapyon-backlog-api`
- `backlog-api`
- `backlog-api-skills`
- 一般語
- 意図しない発火
- 静けさ

## 関係・流れ・対比

```text
「課題」「Wiki」「project」だけ → 発火しない

Skill 名を明示
または Backlog API workflow を明確に依頼
  ↓
発火する
```

## グラレコ構図案

- 左: 一般語が並ぶ静かな待機エリア
- 中央: 明示あり／なしの分岐ゲート
- 右: 明示されたときだけ点灯する Agent Skill とみくく
- みくくの表情・視線: 静かに待機し、点灯したゲートを見る
- 吹き出し: 「呼ばれていないときは、静かに待ちます…」

## 正確性メモ

- 3 つの明示名を正確に書く
- 一般語だけで外部サービスへ接続するように描かない
- 発火しないことを失敗ではなく機能として示す
