# 基本コマンド

- Node.js 版と Java 版の最小実行形
- `--out` を指定すると Markdown をファイルへ保存
- `--out` なしなら stdout
- 通常は後続作業のため `--out` 推奨

## コマンド形

```text
node miku-docx2md.mjs input.docx --out output.md

java -jar miku-docx2md.jar input.docx --out output.md
```

## 短いラベル

- input.docx
- output.md
- stdout
- file output
