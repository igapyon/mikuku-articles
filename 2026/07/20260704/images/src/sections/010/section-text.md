# 共通オプション

- Node.js 版と Java 版の共通引数
- Markdown 出力、asset 出力、summary、debug
- front matter の include / exclude
- verbose は stderr へ診断情報

## オプション群

```text
--out
--assets-dir
--summary-out
--front-matter
--debug
--verbose
--version
--help
```

## 短いラベル

- main output
- optional output
- diagnostics
- metadata
