# セクション008 グラレコ制作用整理テキスト

## 主題

- `miku-md2pptx` のテンプレート適用
- slide size、theme、masters、layouts、placeholder geometry を使う
- Markdown から生成したスライドを載せる

## 図解

```text
template.pptx
  ├─ slide size
  ├─ theme
  ├─ masters
  ├─ layouts
  └─ placeholders

Markdown
  ↓
生成 slides
```

## 注意

- 既存テンプレートスライドはコピーしない
- 出力は Markdown から生成したスライドだけ
- 表、画像、文字量の多いスライドは最終調整が必要

- 「PowerPoint は繊細」
- 「レイアウトへ載せる」
