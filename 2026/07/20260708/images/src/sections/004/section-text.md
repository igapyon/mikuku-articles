# セクション004 グラレコ制作用整理テキスト

## 主題

- 変換だけでは現場ファイルに少し届かない
- Office には見た目と型がある
- テンプレート適用で土台を借りる

## 形式ごとの型

| 形式 | 型の例 |
| --- | --- |
| Word | 見出し、余白、フォント、セクション |
| Excel | 列幅、行高、罫線、シート設定 |
| PowerPoint | テーマ、マスター、レイアウト |

## 図解

```text
内容は合っている
  ↓
見た目が違う
  ↓
手直しが増える
  ↓
テンプレート適用がほしい
```

## 注意

- 高機能 authoring system ではない
- まずは実務に置ける最低限の土台
