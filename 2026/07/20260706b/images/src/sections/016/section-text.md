# セクション整理: おわりに

## 主題

- `miku-md2xlsx` は Markdown を Excel にする小さな出口
- AI agent と人間の作業場所をつなぐ部品

## 流れ

```text
Markdown で考える
  ↓
Markdown で直す
  ↓
Markdown を正本に残す
  ↓
Excel workbook として渡す
```

## メッセージ

- 魔法ではない
- 見出し、本文、表、リンク、画像参照、merge marker を渡す
- 役目を絞ることで道具の輪郭がはっきりする

## 吹き出し案

小さな出口だからこそ、役目をはっきりさせたいのです…！
