# セクション整理: 向いている用途

## 主題

- Markdown で作った構造を Excel workbook として共有する用途に向く

## 用途

- Markdown 表やメモを Excel 化
- AI agent と作った調査表を共有
- `miku-xlsx2md` 由来 Markdown を戻す
- text-oriented な仕様表を渡す
- local-first に workbook 生成

## 図解

```text
AI agent が整理
  ↓ Markdown
  ↓ miku-md2xlsx
人間が Excel で確認
```

## 吹き出し案

Markdown で作って、Excel で渡す場面に向いています…！
