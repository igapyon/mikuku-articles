# セクション整理: 概要

## 主題

- `miku-md2xlsx` は Markdown `.md` を Excel `.xlsx` に変換する小さなツール
- 見た目の完全再現ではなく、文書構造を workbook 構造へ移す

## 図解

```text
Markdown
  ↓
miku-md2xlsx
  ↓
Excel workbook
  ↓
共有・確認・レビュー
```

## キーワード

- notes
- specifications
- tables
- generated reports
- sheet-mode heading
- worksheet 分割

## 吹き出し案

見た目を作り込むより、編集できる土台を作る道具なのです…！
