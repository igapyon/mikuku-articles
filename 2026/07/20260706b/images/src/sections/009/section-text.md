# セクション整理: 共通オプション

## 主題

- Node.js 版と Java 版で共通して使う主要オプション

## オプション

- `--out <file>`
- `--sheet-mode <mode>`
- `--sheet-heading-depth <n>`
- `--title <value>`
- `--table-style <mode>`
- `--no-header-row`
- `--version`
- `--help`

## 図解

```text
入力 Markdown
  + options
  ↓
output.xlsx
```

## 注意

- summary / summary JSON / debug output は確認していない
- 通常変換は最小形から始める

## 吹き出し案

未確認の option を勝手に増やさないのが大事です…！
