# セクション整理: 向いていない用途

## 主題

- Excel の高度な帳票生成や完全復元には向かない

## 向いていない用途

- 美しい完成帳票を自動生成
- 元 Excel workbook の完全復元
- native formula
- native chart / shape / SmartArt
- remote image URL 自動取得
- 高度な formatting
- 完全 round-trip

## 対比

```text
得意: editable workbook foundation
不得意: finished Excel report system
```

## 吹き出し案

Excel 側で仕上げる前提の土台として使います…！
