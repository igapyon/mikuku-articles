# セクション整理: `--help` 出力の確認

## 主題

- 生の `--help` は CLI 契約の確認に役立つ
- usage、inputs、outputs、options、examples、exit codes を一かたまりで確認できる

## 確認ポイント

- Usage
- Inputs
- Outputs
- Generated artifacts
- Diagnostics / warnings
- Exit codes
- Options
- Examples
- Markdown handling notes
- Sheet mode notes

## 注意

- stdout は help / version 用
- conversion progress は machine-readable contract ではない
- missing / remote / absolute image は text reference

## 吹き出し案

迷ったら、まず --help の契約を見ます…！
