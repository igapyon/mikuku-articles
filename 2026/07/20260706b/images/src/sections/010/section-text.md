# セクション整理: 例

## 主題

- よく使う実行例を用途別に並べる

## 例の種類

- XLSX を作る
- heading ごとに sheet を分ける
- `##` heading で sheet 分割する
- plain table style で作る
- Java 版で変換する
- Java 版で heading sheet mode

## 図解

```text
README.md
  ↓ --out README.xlsx
Excel workbook
```

## 注意

- `miku-xlsx2md` 風 Markdown は `--sheet-heading-depth 2`
- table style は `plain` または `bordered`

## 吹き出し案

用途に合わせて、sheet mode と table style を少し足します…！
