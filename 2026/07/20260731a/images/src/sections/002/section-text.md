# ある特定の AI agent で困った

## 主題

- 問題は生成AIモデルの日本語理解ではなく、モデルとファイルの間の agent ハーネス
- UTF-8 前提の検索・読取・patch・保存が Windows-31J を壊しうる
- 失敗せず「成功したように見える」ことが特に怖い

## 図解キーワード

- モデル
- agent ハーネス
- Windows-31J
- UTF-8 前提
- 成功したように見える
- 差分で発覚

## 関係・流れ・対比

```text
生成AIモデル ← 正しくデコードされれば理解できる
      ↑
agent ハーネス ← ここで検索・読取・保存が崩れる
      ↑
Windows-31J ファイル
```

## グラレコ構図案

- 左: Windows-31J ファイル
- 中央: agent ハーネスを通る検索・読取・保存
- 右: 内容を理解できる生成AIモデル
- みくくの表情・視線: 中央のハーネスを心配そうに見る
- 吹き出し: 「モデルが読めない話とは、分けて見るのです…」

## 正確性メモ

- 問題の主体をモデル全般やすべての AI agent へ広げない
