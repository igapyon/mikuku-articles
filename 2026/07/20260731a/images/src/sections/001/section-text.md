# はじめに

## 主題

- Windows-31J のファイルが AI agent の操作で文字化けした
- 目の前の既存ファイルを守るため、専用 Agent Skills を作った
- ベータ版で対象は狭く、将来すぐ不要になる可能性もある

## 図解キーワード

- Shift_JIS / Windows-31J
- 文字化け
- Java / JSP
- Agent Skills
- 目の前のファイルを守る

## 関係・流れ・対比

```text
UTF-8 前提の道具 → Windows-31J → 文字化け
困りごと → 専用の道具を作る → ファイルを守る
```

## グラレコ構図案

- 左: 文字化けした Java / JSP と困る AI agent
- 中央: `miku-text-file-ops` と `miku-text-file-ops-skills`
- 右: 元の文字コードを保ったファイル
- みくくの表情・視線: 右端で心配そうに中央を見る
- 吹き出し: 「まず、目の前のファイルを守りたかったのです…」

## 正確性メモ

- すべての AI agent の問題とは書かない
- 両ツールは記事作成時点でベータ版
