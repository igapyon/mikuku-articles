# グラレコ制作用整理テキスト

## 1. 記事の大テーマ

- Codex に GPT-5.6 の入口が3つ増えた
- Sol / Terra / Luna の第一印象
- 公式説明と credits 差を見て、最初の使い分けを作る

```text
GPT-5.6
  ├─ Sol   = 難しい仕事 / 最上位
  ├─ Terra = 普段使い / バランス
  └─ Luna  = 軽い仕事 / 高速・低コスト
```

- 日付: 2026年7月11日
- 場所: Codex のモデル選択

## 4. 3モデルの役割

| モデル | 役割 | 向く作業 |
| --- | --- | --- |
| Sol | 最上位 | 複雑な変更、難しい調査、仕上げ |
| Terra | バランス | 普段の開発、調査、文書更新 |
| Luna | 高速・低コスト | 軽い修正、単純確認、大量処理 |

## 6. とりあえずの選び方

- 迷ったら Terra
- 難しくなったら Sol
- 軽い仕事なら Luna
- Sol でも reasoning effort は低めから始める

```text
普段の作業 → Terra
複雑な作業 → Sol
軽い作業   → Luna
```
