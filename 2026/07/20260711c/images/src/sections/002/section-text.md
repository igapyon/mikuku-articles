# Codexのモデル選択に3つ追加

## 主題

- Codex に GPT-5.6 Sol / Terra / Luna が追加
- 同じ世代の中で、性能・速度・コストの階層が分かれる

## 役割分担

| モデル | Codex 表示 | ざっくり |
| --- | --- | --- |
| Sol | frontier | 複雑で難しい仕事 |
| Terra | balanced | 日常作業 |
| Luna | fast and affordable | 軽い作業・大量処理 |

## 対比

```text
Sol   = 太陽 / 最上位
Terra = 地球 / 普段使い
Luna  = 月   / 軽量
```

## グラレコ構図案

- 宇宙っぽい小さな星図
- 3つの入口を横並び
- ただし SF 過多にしない
- 吹き出し: 「入口ごとに、お願いする仕事が少し違います…」
