# 014. summary と front matter

## 主題

- combined Markdown の先頭に YAML front matter
- summary は全体像の補助情報

## front matter fields

- title
- type
- conversion.tool
- conversion.version
- conversion.output_mode
- conversion.formatting_mode
- conversion.table_detection_mode
- conversion.shape_details

## summary で見るもの

- sections
- tables
- narrative blocks
- merged ranges
- images / charts / comments
- analyzed cells
- formula status counts
- table candidate score

## 関係

```text
front matter = 変換設定の足場
summary      = 変換結果の全体像
Markdown本文 = 読むための本体
```

## 吹き出し案

「本文を読む前に、summary で地図を見るのです…」
