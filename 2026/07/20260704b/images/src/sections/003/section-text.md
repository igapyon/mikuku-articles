# 表現対応表

- Markdown 表現が Word の構造へ変換される

| Markdown | Word |
| --- | --- |
| paragraph | Normal paragraph |
| heading | Heading1-6 |
| list | bullet / ordered list |
| pipe table | Word table |
| fenced code | Code style |
| inline code | CodeChar |
| link | hyperlink |
| local image | embedded image |
| front matter | excluded |

- Node.js v0.9.2 が細かな構文の基準
- Java v0.9.1 は代表ケース parity
- summary で missing image / unresolved link を確認
