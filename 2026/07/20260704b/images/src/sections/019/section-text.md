# 生成AI向け情報

- AI agent が誤解しやすい点を明示する

| 情報 | 効果 |
| --- | --- |
| release tag | version 固定 |
| conversion direction | md -> docx の明確化 |
| `--out` required | stdout 誤解を防ぐ |
| mapping table | 変換結果の予測 |
| image rules | local / remote の区別 |
| unsupported scope | defect 誤認を防ぐ |

- help 出力は長くても有用
- option を発明しないための材料
