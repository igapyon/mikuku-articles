# おわりに

- `miku-md2pptx` は小さな出口
- Markdown で考える
- Markdown で直す
- Markdown を正本として残す
- PowerPoint deck として人間に渡す

```text
AI agent の作業場所
  Markdown
    ↓
人間の説明場所
  PowerPoint deck
```

輪郭:

- PowerPoint の見た目を全部作り込む魔法ではない
- 見出し、本文、リスト、表、リンク、画像、speaker notes を渡す
- 役目を絞ることで道具の輪郭がはっきりする

トーン:

- 小さいけれど大事な部品
- 入口と出口を丁寧に整理
