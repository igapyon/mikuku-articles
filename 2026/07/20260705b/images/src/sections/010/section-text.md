# 例

- 実行例で最小形を示す
- title 指定の形も示す
- Node.js と Java で command shape を分ける

```text
PPTX を作る
  node ... README.md --out README.pptx

title を指定
  node ... README.md --out README.pptx --title "README overview"

Java 版
  java -jar ... README.md --out README.pptx
```

図解ポイント:

- 入力ファイル
- 変換器
- 出力ファイル
- title option

注意:

- 実行形は似ているが runtime は別
