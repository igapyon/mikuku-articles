# はじめに

- みくくが `miku-md2pptx` を紹介
- Markdown `.md` から PowerPoint `.pptx` へ
- `miku-pptx2md` の反対向き
- 入口: PowerPoint を Markdown へ
- 出口: Markdown を PowerPoint deck へ
- 目的は「人間に渡せる土台」

```text
Markdown で考える
  ↓
PowerPoint が必要
  ↓
miku-md2pptx
  ↓
編集可能な deck
```

強調:

- 完成デザインではなく構造変換
- 見出し、本文、リスト、表、画像、リンク、speaker notes を移す
- AI agent と人間の作業場所をつなぐ
