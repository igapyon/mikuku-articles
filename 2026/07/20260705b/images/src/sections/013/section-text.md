# 向いている用途

- Markdown の説明骨子を PowerPoint 化
- AI agent と作った議論メモを slide deck にする
- text-oriented な研修資料や説明資料のたたき台
- local-first に PowerPoint deck を生成
- `miku-pptx2md` と組み合わせて代表構造を確認

流れ:

```text
Markdown で構造を作る
  ↓
miku-md2pptx で deck 化
  ↓
PowerPoint 側で見た目や説明順を調整
```

キーワード:

- 正本を残す
- deck として共有
- 説明、レビュー、研修
- 編集できる土台
