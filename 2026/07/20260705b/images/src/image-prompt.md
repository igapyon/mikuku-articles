# Image Generation Prompt

Create a wide horizontal graphic recording style educational poster for a Japanese technical article about `miku-md2pptx`, a small tool that converts Markdown files into editable PowerPoint `.pptx` decks.

## Canonical Mikuku Character Prompt

Use this as the canonical character prompt for Mikuku. Same character, do not redesign, preserve character identity, canonical character reference:

masterpiece, best quality, ultra-detailed anime portrait, head-and-shoulders 1girl, shy uneasy expression, slight 3/4 view, looking to her right and slightly upward.

Warm chestnut-brown eyes with gold flecks, soft blush, worried upward-slanted brows, small downturned pout, fair warm skin, delicate V-U shaped chin.

Soft caramel-chestnut very long twin-tails tied high with black ribbons and deep-red trim, silky wavy hair, asymmetrical curtain bangs, long side strands framing cheeks.

Thin clean line art, soft cel shading, watercolor-like shading, subtle rim light, warm minimal background.

## Layout

- Wide horizontal poster, 16:9.
- Left and center: dense but readable hand-drawn graphic recording diagram.
- Right side: Mikuku gently explaining the diagram, looking toward the diagram.
- Mikuku must not hold any objects.
- Keep hands simple and relaxed, partly hidden if needed.
- Clean Japanese anime style, soft bright light, note.com friendly visual brand.

## Main Visual Story

Show the flow:

`Markdown 正本` -> `miku-md2pptx` -> `PowerPoint deck` -> `人間に渡す`

Use boxes, arrows, small icons, and short Japanese labels. The poster should make it clear that the tool is a structural converter, not a pixel-perfect PowerPoint design system.

## Include These Concepts

- Title label: `Markdown を PowerPoint へ`
- `miku-md2pptx`
- `小さな出口`
- `編集可能な .pptx`
- `practical slide structure`
- `not pixel-perfect layout`
- `# / ## heading = new slide`
- `paragraph / list / table / image / link / speaker notes`
- `Node.js v0.2.2`
- `Java v0.2.3`
- `--out は必須`
- `local-first`
- `AI agent と人間の作業場所をつなぐ`

## Diagram Ideas

1. Main pipeline:
   - Markdown document icon
   - converter box labeled `miku-md2pptx`
   - PowerPoint deck icon
   - human review / meeting icon

2. Mapping table mini-panel:
   - heading -> slide
   - paragraph -> text
   - list -> bullet
   - table -> native table
   - local image -> embedded image
   - speaker notes -> notesSlide

3. Runtime comparison mini-panel:
   - Node.js v0.2.2: runtime root based relative path
   - Java v0.2.3: current working directory based relative path

4. Unsupported scope mini-panel:
   - pixel-perfect design: no
   - remote image auto download: no
   - raw HTML full conversion: no
   - perfect round trip: no

## Style

Hand-drawn graphic recording, cozy technical explainer, whiteboard note style, soft colored lines, small icons, arrows, rounded boxes, gentle beige paper background with restrained pastel accents. Use readable-looking short labels, not long paragraphs. High detail, balanced composition, cute but practical.

## Speech Bubble

Add a small speech bubble from Mikuku:

「あ、あの…Markdown の構造を、PowerPoint の土台へ渡す出口なのです…！」

## Negative Constraints

Do not create a corporate slide deck screenshot. Do not make it dark or sci-fi. Do not make Mikuku hold a pen, pointer, notebook, board, or any object. Do not redesign Mikuku. Avoid broken hands and extra fingers. Avoid huge unreadable walls of text.
