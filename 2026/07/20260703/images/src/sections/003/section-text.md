# Markdown に寄せるもの

## 主題

- プレーンテキストだけではない
- Markdown に載せやすい情報を拾う
- 完全再現ではなく意味のある情報を優先

## 情報の種類

| Office | Markdown へ寄せる情報 |
| --- | --- |
| Word | 本文、表、コメント、校閲系テキスト |
| Excel | 表、簡単な Excel 方眼 |
| PowerPoint | スライド内テキスト |

## 図解

```text
複雑な Office
  ↓ 取捨選択
意味のあるテキスト情報
  ↓
Markdown 化
```

## 短いラベル

- 拾える範囲で
- テキスト情報
- 表
- コメント
- 校閲
- スライド内テキスト
