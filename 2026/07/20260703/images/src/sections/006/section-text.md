# 向いている使い方

## 主題

- Office の中身をまず読める形にする
- 手作業コピーの前に Markdown 化
- AI agent との作業入口を楽にする

## 具体例

- Word の仕様メモ
- Excel の一覧表
- PowerPoint のスライド内テキスト
- Office と Markdown の比較
- 手元資料を軽い .md に

## 図解

```text
何度もコピー
  ↓ 大変
変換ツール
  ↓
まず .md
  ↓
AI agent と作業
```

## 短いラベル

- まず中身を読める形に
- 小さな手間を減らす
- 資料が増えるほど効く
