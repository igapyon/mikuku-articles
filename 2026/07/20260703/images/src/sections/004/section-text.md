# 何がうれしいのか

## 主題

- Office をそのまま扱う前に Markdown 化
- 確認、要約、比較、差分がしやすい
- AI agent に渡す前の情報整理

## 作業の流れ

```text
Office
  ↓
.md
  ↓
確認 / 要約 / 比較 / 差分
  ↓
AI agent に渡す
```

## うれしいこと

- 本文確認
- 要約
- 関連メモと比較
- リポジトリ差分
- 他の Markdown と並べる
- 不要部分を削る
- 消費トークンを抑えられる場合

## 短いラベル

- 作業資料化
- 軽いファイル
- テキスト中心
- 次の作業へ
