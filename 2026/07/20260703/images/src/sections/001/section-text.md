# はじめに

## 主題

- miku-ms-office-skills の紹介
- Office ファイルを AI agent 向け Markdown へ
- 完成文書ではなく作業資料へ寄せる

## 図解

```text
Office ファイル
  ↓
読みやすい情報を抽出
  ↓
GitHub風 Markdown
  ↓
AI agent の入口
```

## 短いラベル

- OSS Agent Skills
- Word / Excel / PowerPoint
- GitHub風 Markdown
- ベータ版
- 小さな入口
- 地味な前処理

## 対比

| ではない | である |
| --- | --- |
| 見た目の完全再現 | AI agent 用の作業資料 |
| 派手な変換 | 地味な前処理 |
| 完成物 | 次作業への入口 |
