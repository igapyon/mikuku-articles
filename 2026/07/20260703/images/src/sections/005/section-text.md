# 割り切っているところ

## 主題

- 万能変換ツールではない
- AI agent に渡すための Markdown 化に絞る
- ローカルで軽く再現しやすく

## 使わないもの

- AI
- OCR
- ネットワーク越しの変換サービス

## 図解

```text
手元の runtime
  ↓
ローカル変換
  ↓
Markdown
```

## 対比

| 優先する | 優先しない |
| --- | --- |
| テキスト抽出 | 見た目の再現 |
| 軽さ | 大きな仕組み |
| 再現しやすさ | 万能性 |

## 短いラベル

- ローカル実行
- LLM/API 不要
- Node.js or Java
- 地味な安定
