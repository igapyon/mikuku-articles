# 011 ベータ版として育てています

## 主題

Office ファイルには作り手ごとの癖があるため、ベータ版として範囲を広げすぎず育てる。

## 図解キーワード

- beta
- file variety
- Word paragraphs
- Excel merged cells
- PowerPoint shapes
- gradual improvement

## 図解したい構造

```text
実ファイルで試す
  ↓
できる範囲を確認
  ↓
改善する
  ↓
次の版へ
```

## 注意点

- どんな Office ファイルでも大丈夫、とは言わない
- AI agent が読むテキスト情報を Markdown にする用途を重視
- 無理に対応範囲を広げすぎない

## 吹き出し案

「少しずつ、試して直していきます…」
