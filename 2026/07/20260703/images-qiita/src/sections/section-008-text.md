# 008 何がうれしいのか

## 主題

Office ファイルを Markdown にしておくと、AI agent との後続作業がしやすくなる。

## 図解キーワード

- read
- summarize
- compare
- diff
- cleanup
- next Agent Skills

## 図解したい流れ

```text
Office file
  ↓
Markdown
  ↓
確認 / 要約 / 比較 / 差分 / 次の作業
```

## 価値

- 本文確認しやすい
- 要約しやすい
- Markdown資料と並べやすい
- リポジトリ内で差分を見やすい
- 不要部分を削って AI agent に渡しやすい

## 吹き出し案

「次の作業へ進む入口になります…」
