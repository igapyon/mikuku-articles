# 007 通常変換では主出力だけを作る

## 主題

通常変換では主出力だけを作り、summary や debug、assets、zip は明示依頼時だけにする。

## 図解キーワード

- primary output only
- Markdown only
- opt-in extras
- fewer artifacts
- less confusion

## 図解したい流れ

```text
普通の「変換して」
  ↓
primary output only
  ↓
AI agent が読むファイルが明確
```

## 追加出力

必要なときだけ:

- summary
- debug
- assets
- zip
- diagnostics

## 吹き出し案

「出しすぎないのも大事です…」
