# グラレコ制作用整理テキスト

対象記事: `20260707-general-codex-davinci-resolve-video-workflow.md`

# 1. 大テーマ

専門ツールは、AI agent と組み合わせると少し近くなる。

```text
素材 / 音声 / ツール
  ↓
AI agent が確認・整理・配置を支援
  ↓
DaVinci Resolve のタイムライン
  ↓
人間が目と耳で判断
  ↓
操作ログが次の Agent Skill へ育つ
```

# 2. この記事の中心メッセージ

- 完全自動化ではない
- 入口の重さが下がる
- 細かい操作は agent に渡しやすい
- 品質判断は人間に残る
- 操作ログは次回の Skill の種になる

# 3. 役割分担

| 要素 | 役割 |
| --- | --- |
| Windows 11 | 作業環境 |
| ffmpeg | 動画・音声の確認、変換、切り出し |
| DaVinci Resolve Studio | 編集タイムライン |
| VOICEVOX / ずんだもん | ナレーション音声 |
| OpenAI Codex app | 作業の整理と実行補助 |
| 人間 | 目的、素材選択、品質判断、公開可否 |

# 4. Before / After

```text
Before:
  専門ツールの画面を覚える
  素材を手で確認
  操作で迷う
  途中で疲れる

After:
  やりたいことを言葉にする
  agent が確認・整理
  タイムライン作業を支援
  人間は判断へ集中
```

# 5. 流れ

```text
準備
  ffmpeg / Resolve / VOICEVOX / 素材確認
    ↓
制作
  取り込み / タイムライン / 切り詰め / 音声配置
    ↓
確認
  映像の間 / 声 / テンポ / 公開品質
    ↓
蓄積
  作業ログ / 手戻り / よい指示
    ↓
Agent Skill 化
```

# 6. 重心の変化

- 「ツールの全操作を覚える」から「何を作りたいかを言う」へ
- 「直接操作」から「agent と一緒に扱う」へ
- 「手順の暗記」から「判断と言語化」へ
- 「一度きりの作業」から「再利用できる Skill」へ

# 7. 注意点

- DaVinci Resolve Studio 前提は環境差がある
- VOICEVOX とキャラクター利用規約の確認が必要
- AI agent が全部を保証するわけではない
- 最後の品質判断は人間が行う

# 8. まとめ

専門ツールは消えない。けれど、AI agent が横にいると入口が軽くなる。

人間の役割は、細かい操作から「目的」「判断」「違和感の言語化」へ移る。

作業ログを整理すれば、次の Agent Skill として育てられる。
