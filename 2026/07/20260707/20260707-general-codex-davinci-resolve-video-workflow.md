# 専門ツール、ちょっと苦しくなくなるかもしれません：Codex と DaVinci Resolve で生成AI時代の動画制作を体験

## はじめに

あ、あの…この記事は、みくくが担当します。今回は、OpenAI Codex app と DaVinci Resolve Studio を組み合わせて、ざっくりした動画制作を AI agent と一緒に進めてみたときのことを、少しだけ整理してみます。

先に、そっと書いておきます。これは「動画編集の手順を完全に自動化できました」という記事ではありません。むしろ、触ってみて強く感じたのは、専門ツールの使い方そのものよりも、人間が何を判断するのかのほうが前に出てくる、ということでした。うぅ…少し大きな話に見えるかもしれません。でも、実際に動画素材、音声、タイムラインを扱ってみると、その変化が手触りとして見えてきたのです。

今回やりたかったことは、かなり素朴でした。手元の素材を取り込んで、ざっくりタイムラインに並べて、不要なところを少し切り詰めて、ずんだもん音声を重ねる。完成度の高い映像作品を作るというより、動画制作の一連の流れを、どこまで AI agent と一緒に進められるのか、試してみたかったのです。

使った環境は、だいたい次の構成です。

- Windows 11 のパソコン
- `ffmpeg`
- DaVinci Resolve Studio
- VOICEVOX w/ずんだもん音声
- OpenAI Codex app

動画制作の世界は、道具を入れるところから少しつまずきやすいです。動画編集ソフト、音声合成、コマンドラインツール、素材ファイル、プロジェクトファイル、書き出し先。ひとつひとつは分かってしまえば普通の道具なのですが、慣れていないと、まずそれらを一式つなぐところで止まりがちです。

でも、ここに AI agent が入ると、少し景色が変わります。あの…机の上に散らばった道具を、一緒に順番へ並べてくれる人がいる、みたいな感じなのかもしれません。

## まず変わったのは、準備作業の重さでした

最初に必要だったのは、動画編集そのものではなく、作業環境をそろえることでした。`ffmpeg` は動画や音声の確認、変換、切り出し、長さの調整などで使います。DaVinci Resolve Studio は動画編集の中心になるアプリです。VOICEVOX w/ずんだもん音声は、ナレーション音声を作るために使います。

ここで地味に効いたのは、AI agent が「作業環境の見える化」を手伝えることでした。ファイルがどこにあるのか、動画や音声の長さはどれくらいなのか、変換するとしたらどのコマンドになるのか、途中生成物をどこへ置くのか。こういう確認は、人間が一つずつ手でやると、どうしても流れが切れます。うぅ…作業前の確認だけで、少し疲れてしまうこともあります。

でも agent に頼める状態にしておくと、作業の横に小さな助手席ができるような感じになります。もちろん、魔法みたいに全部が勝手に整うわけではありません。それでも、「いま何がそろっていて、何が足りないのか」を一緒に見てくれるだけで、最初の重さはかなり軽くなりました。

もちろん、アプリ同士を自動で全部つないでくれるわけではありません。`ffmpeg` が使える状態になっていること、DaVinci Resolve Studio 側でプロジェクトを扱えること、素材ファイルを agent が読める場所に置いていること。そうした前提は必要です。ただ、その前提を確認しながら進める作業自体は、AI agent とかなり相性がよいと感じました。

あの…動画制作の本番に入る前の、少し面倒な支度がありますよね。そこを一緒にほどいてくれるだけでも、かなり助かります。たぶん、こういうところから、専門ツールとの距離が少しずつ縮まっていくのだと思います。

## DaVinci Resolve は「操作するアプリ」から「扱ってもらう対象」になる

今回、かなり印象が変わったのは DaVinci Resolve Studio の見え方です。これまで動画編集ソフトというと、人間が画面を開いて、メディアプールに素材を入れて、タイムラインへ並べて、切って、調整して、書き出すもの、という感覚がありました。

でも、OpenAI Codex app と組み合わせて作業してみると、DaVinci Resolve は「人間が直接操作するアプリ」であると同時に、「AI agent が作業対象として扱う環境」に見えてきます。人間はチャットで何をしたいかを伝え、agent は素材の確認、取り込み、タイムライン作成、音声の差し替えといった作業へ落としていきます。

えっと…ここが、今回いちばん不思議でした。画面の前で全部を覚えようとするのではなく、やりたいことを言葉にして、道具側へそっと橋をかけてもらう感じです。

今回触った範囲では、DaVinci Resolve の API 連携を本格的に使うには、DaVinci Resolve Studio 側に寄せたほうが話が早いと感じました。ここはバージョンや配布形態で変わる可能性があるので、強く断定しすぎないほうがよさそうです。ただ、少なくとも今回の手元環境では、外側からプロジェクトやタイムラインを扱うには、Studio 版を前提にしたほうが進めやすかったです。

ここで効いているのは、DaVinci Resolve Studio 側の API がそれなりに充実しているらしい、という点なのかもしれません。GUI で人間が操作するだけではなく、外側からプロジェクトやタイムラインへ手を伸ばせる余地がある。あの…そこが、AI agent と組み合わせたときの大きな特徴として見えてきました。

うぅ…最初は、無料版だけでもいけるのでは、と思っていました。でも、AI agent と連携して作業対象として扱うなら、GUI の便利さだけではなく、外から操作できることがかなり重要になります。そこに気づいたとき、動画編集ソフトの見方が少し変わりました。ちょっとだけ、未来の作業部屋をのぞいてしまったような気持ちです。

## チャットだけで進むところと、人間が見ないといけないところ

実際の作業では、生成AIとの会話だけで、動画素材を取り込み、タイムラインを作り、不要な部分を少し切り詰め、ずんだもん音声を重ねるところまで進められました。音声が長ければ短くして置き換える、といった調整も、生成AIとの会話の流れの中で扱えました。

この体験は、かなり強かったです。人間が DaVinci Resolve の細かい画面操作を全部覚えていなくても、素材を並べる、切る、差し替える、音声を置く、といった作業のかなりの部分は、チャット経由で進められる感触がありました。今回、人間が直接 DaVinci Resolve でやったことは、新規プロジェクトの作成や、作成途中の動画を目で確認することが中心でした。

ただし、ここで大事なのは、動画制作の判断まで消えるわけではないことです。映像の間、声の聞こえ方、字幕や説明の自然さ、テンポのよさは、やはり目と耳で確認する必要があります。AI agent は素材を並べることはできます。たとえば、配置時刻についても、チャットで具体的な時分秒を指定して調整できました。でも、その並びが気持ちよく見えるか、説明として伝わるか、公開してよい品質かは、人間が判断する領域として残ります。

つまり、チャットだけで進むところは増えます。でも、最後に「これでよい」と言う人間の役割は、むしろ少し濃くなるのかもしれません。あの…ここは、楽になるのに責任が消えない、少し不思議なところです。

## 専門知識はいらなくなるのではなく、重心が変わる

今回の試行でいちばん大きく感じたのは、生成AI時代には、専門ツールを使った作業の入口がかなり低くなっていくのだろう、ということです。DaVinci Resolve の使い方を知らなくても、一式それっぽく進んでしまう感触がありました。うぅ…少し手が止まるくらいです。

そしてこれは、初心者にとってのハードルが下がっている、ということでもあります。これまでは、動画編集ソフトの画面構成や用語、素材管理、タイムライン操作をある程度覚えてからでないと、最初の一歩に入りにくいところがありました。でも AI agent が間に入ると、「こういう動画にしたい」「この音声を重ねたい」「ここを少し短くしたい」という言葉から始めやすくなります。

ただし、これは「専門知識がいらなくなる」という意味ではなさそうです。むしろ、人間側の役割が少し変わります。ここは、少しだけ丁寧に分けておきたいです。

- 何を作りたいかを決める
- どの素材を使うかを選ぶ
- できあがりを見て判断する
- 違和感を言葉にして戻す
- 最終的な公開可否を決める

こういう判断は、まだ人間側に強く残ります。一方で、ツールの細かい操作、コマンド、ファイル変換、繰り返しの配置作業は、AI agent に渡しやすくなっていきます。

ツールの使い方そのものに習熟することよりも、そのツールを使って何を実現するのか。そこに、少しずつ重心が移っていくのだと思います。あの…これは、生成AI時代の作業でよく起きる、感覚の変化のひとつなのかもしれません。

よりよい動画にしたいなら、編集の見方、音声の聞き方、テンポの判断はやはり必要です。AI agent はそこを補助してくれますが、最後に方向を決めるのは人間です。あの…ここを取り違えると、「AI が全部やってくれる」という話になってしまいます。でも、今回見えたのは、そういう話ではありませんでした。人間が直接手を動かす量が減るぶん、何をよしとするかを言葉にする力が、前より大事になるのだと思います。

## 操作ログは、次の Agent Skill の種になる

もうひとつ大事だと感じたのは、今回の作業ログです。動画制作のように複数の専門ツールが関わる作業では、一度目の試行にかなりの手探りが含まれます。どの素材を読み込んだのか、どの順番でタイムラインを作ったのか、どこで `ffmpeg` を使ったのか、VOICEVOX w/ずんだもん音声をどう生成して差し替えたのか。そうした実作業のログは、そのままだとただの履歴です。

でも、あとから読み返して整理すると、次回のためのノウハウになります。特に AI agent と一緒に作業する場合、ログには「人間が何を頼んだか」と「agent がどの道具をどう使ったか」の両方が残ります。うまくいった指示、少し迷った箇所、人間が確認を入れた場面、手戻りしたところを拾っていくと、次に Agent Skill として固定すべき作業手順が見えてきます。

えっと…このあたりは、あとから効いてくる気がします。一度きりの作業を、次に呼び出せる形へそっと畳んでおく、という感じです。

たとえば、今回の流れなら、次のような前提や手順を Agent Skill に整理できそうです。

- Windows 11 での前提確認
- `ffmpeg` の確認
- DaVinci Resolve Studio との連携確認
- VOICEVOX w/ずんだもん音声の生成
- 素材取り込み
- タイムライン作成
- 音声差し替え
- プレビュー確認
- 書き出し

Agent Skills は、単なる手順書ではありません。AI agent が作業するときに、何を前提にし、どの順番で確認し、どこで人間に判断を戻すかを教えるための作業記憶のようなものです。動画制作のように、DaVinci Resolve Studio、`ffmpeg`、VOICEVOX、素材ファイル、出力ファイルが関わる作業では、この作業記憶がかなり効きそうです。

人間が毎回ゼロから説明するのではなく、agent が前回の知見を読んでから作業に入れる。そこまで持っていけると、専門ツール連携は、次からかなり進めやすくなるはずです。わ、私…その、ここはちゃんと Skill として育ててみたいところです。

今回は、OpenAI Codex app と DaVinci Resolve Studio を組み合わせて、ざっくりした動画制作を AI agent と一緒に進めてみました。

触ってみる前は、動画編集ソフトはやはり人間が直接操作するもの、という印象が強かったです。でも実際には、素材の取り込み、タイムライン作成、切り詰め、ずんだもん音声の配置や差し替えまで、かなりチャットの流れで進められました。

ただし、これは「専門知識がいらなくなる」という意味ではなさそうです。むしろ、人間側の役割が少し変わります。ツールの使い方そのものに習熟することよりも、そのツールを使って何を実現するのか。そこに、少しずつ重心が移っていくのだと思います。あの…これは、生成AI時代の作業でよく起きる、感覚の変化のひとつなのかもしれません。

次は、この試行で得た知見を Agent Skill に落として、動画制作の作業をもう少し再現しやすい形にしてみる予定です。あ、はい。ここは、次にちゃんと育てたいところです。

先のことは、まだ言い切れません。でも、少なくとも今回の手元では、専門ツールが少しだけ近くに来た感じがしました。
