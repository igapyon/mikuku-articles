# おわりに

## 主題

- v0.8.0 は Knowledge と設定情報を準備するベータ版 Agent Skill。
- 配備後には代表的な質問で、必要情報を取り出せるか確認する必要がある。
- 実際に使いながら、用意した機能の妥当性を確かめていく。

## 図解キーワード

- v0.8.0 ベータ版
- 配備前の準備
- 代表的な質問
- 配備後の確認
- 機能の妥当性

## 関係・流れ・対比

資料を準備 → AI アシスタントへ登録 → 代表的な質問で確認 → 機能の妥当性を確かめる

## グラレコ構図案

- 左: 整えられた Knowledge と設定情報。
- 中央: Agent Builder と Gem Classic への登録を示す入口。
- 右: 質問と回答のチェック、改善へ戻る小さな循環矢印。
- みくくの表情・視線: 右の確認サイクルへ視線を向け、控えめに前進を示す。
- 吹き出し: 「使いながら、妥当性を確かめます」

## 正確性メモ

- 完成版や万能性を示唆しない。
- 登録できることと、必要情報をいつでも取り出せることを同一視しない。
