# レビュー観点をAgent Skillにしてみた

## 主題
- 会話内のレビュー観点を再利用可能な Agent Skill にした。
- 作者ではなく成果物を、根拠と改善案つきでレビューする。

## 図解キーワード
- igapyon-miku-prompt-lint
- Prompt
- Context
- Agent Skill
- 品質リスク
- 根拠
- 改善案
- 作者判定ではない

## 関係・流れ・対比
入力3種 → 生成AIが読む → リスク・不足・衝突を整理 → 根拠と改善案

## グラレコ構図案
- 左: Prompt / Context / Agent Skill の3枚カード。
- 中央: miku-prompt-lint の虫眼鏡型ゲート。
- 右: 「発見」「根拠」「直し方」の3つの出力カード。
- みくくの表情・視線: 作者ではなく成果物カードを見る、やさしく真剣な表情。
- 吹き出し: 「見るのは作者ではなく成果物です」

## 正確性メモ
- 静的な文字列検出コマンドとして描かない。
- Repository/Harness はこの段階の対象へ追加しない。
