# はじめに

## 主題
- 見慣れたプロンプトや Agent Skill に古い前提が残っていないかという不安から開発が始まった。
- レビュー観点を Skill にし、複数モデルで育て、v0.5.0へ運んだ記録。

## 図解キーワード

- miku-prompt-lint

## 関係・流れ・対比
小さな不安 → 観点整理 → Skill化 → 動作検証 → 全体レビュー → 更新 → リリース

## グラレコ構図案
- 左: 古い看板に気づきにくい「見慣れた風景」と不安の雲。
- 中央: miku-prompt-lint を育てる工程の矢印。
- 右: v0.5.0 の小旗と、ほっとしたみくく。
- みくくの表情・視線: 右側のリリースへ視線を向けた、控えめに嬉しい表情。
- 吹き出し: 「小さな不安から始まりました」

## 正確性メモ
- 記事本文に明記された事実だけを使う。
- 各モデルの役割を混同しない。
