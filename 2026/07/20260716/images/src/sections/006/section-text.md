# Sol Ultraでレビューし、Terra Mediumで更新した

## 主題
- Sol Ultra、Terra Medium、人間でレビュー・修正・判断を分担した。
- 対象を4 Review Levelへ広げ、検証と配布の契約も整えた。

## 図解キーワード
- Sol Ultra: 全体レビュー
- Terra Medium: 修正・テスト・文書
- 人間: 採用・リリース判断
- Prompt
- Context
- Agent Skill
- Repository/Harness
- contract test

## 関係・流れ・対比
Sol Ultra（広く発見） → 人間（指摘を確認・採用） → Terra Medium（変更・検証） → 人間（差分・リリース判断）

## グラレコ構図案
- 左: Sol Ultraがリポジトリ全体を俯瞰するカード。
- 中央: 人間を中心にした役割分担の矢印と4 Review Level。
- 右: Terra Mediumが修正、テスト、文書をそろえるカード。
- みくくの表情・視線: 中央の人間判断を大切そうに示す真剣な表情。
- 吹き出し: 「判断は人間が閉じます」
