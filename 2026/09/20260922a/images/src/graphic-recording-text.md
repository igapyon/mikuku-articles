## 関係・流れ・対比

### 数え方

```text
GitHub 公開リポジトリ
  └─ 既定 branch devel の `SKILL.md`
       └─ 15リポジトリ / 28件
```

- 中央リポジトリ 1つ → 14件
- 用途別の専用リポジトリ 14個 → 14件
- 合計 15リポジトリ → 28件
- `igapyon-agent-skills` のテスト fixture、fork、`SKILL.md` を確認できないものは数えない
- 28件は2026年7月24日時点の公開状態を写したスナップショット

### 使われ方の対比

| 使われ方 | 記事に出てくる例・意味 |
| --- | --- |
| 頻繁に使う | `igapyon-miku-scm`、`igapyon-miku-soft-developer`、`igapyon-mikuku-agent`、`igapyon-miku-indexgen` |


## 役割分担・判断軸

| 要素 | 役割・見方 |
| --- | --- |
| `SKILL.md` | 数える基準。Agent Skill の実在を確認する入口 |

| 頻繁に使う | 今の作業で前面に出ている道具 |
| 間接的に支える | 正本、規約、検索・bundle など作業の前提を安定させる道具 |

- 判断軸は「呼び出し回数」だけではない
- 必要なときに迷わず使えるか、次に育てる場所が見えるかも価値
- 全部を均等に使う必要はない

## 正確性メモ

- 数値は記事本文にある `15リポジトリ`、`28件`、`14件 + 14件` だけを使う
- 数えた基準は GitHub 公開リポジトリの既定 branch `devel` にある `SKILL.md`。時点は2026年7月24日
- テスト fixture、fork、名前に Skill とあるだけで `SKILL.md` を確認できないものは除外
- 画像内の代表例は記事本文に記載された Skill 名だけにする
- 「使われ方」は記事の分類を短く整理したもので、優劣や人気ランキングを意味しない
- 画像生成時点のモデル名、生成環境、追加の評価、最新の件数は足さない
