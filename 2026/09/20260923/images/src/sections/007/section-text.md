# おわりに

## 主題

- 小学校国語の「伝え合いの基本」を、生成AIとの会話にも応用できる
- 背景を伝え、回答を受けて調整し、感想や試した結果を返して次につなぐ
- まずは「よかった点」や「試した結果」を一言返す小さな実践から始める

## 図解キーワード

- 背景を伝える
- 回答を読む
- 伝え方を調整
- よかった点
- 試した結果
- 次の話
- 伝え合いの基本
- 小さな一歩

## 関係・流れ・対比

- 背景を伝える → 回答を受ける → 伝え方を調整 → 感想・試した結果を返す → 次の話
- 大きな準備より、短い一言から始める

## 図解構造

- layout-family: cycle
- primary-relation: 小さなフィードバックから始まる生成AIとの会話の循環

## グラレコ構図案

- 左: 背景や目的を伝える短いメッセージカード
- 中央: 回答を読み、伝え方を調整する循環矢印
- 右: 「ここはよかった」「試したらこうなった」の2つの吹き出しから次の相談へつなぐ
- みくくの表情・視線: 右下で少し照れながらも前向きな表情、二つの一言から循環の先を見る
- 吹き出し: 「一言返すところから」

## 正確性メモ

- 記事本文に明記された事実だけを使う
- 生成AIとの会話を一方向の依頼で終わらせず、応答を受けた反復として描く
- 効果を保証せず、記事が勧める小さな始め方として示す

## 共通スタイル契約

- style-profile: mikuku-graphic-recording-v1
- 横長 3:2、左・中央・右の3領域、主図を最大化
- みくくは説明役として読める大きさで1人、短い吹き出しを1つ、物を持たない
